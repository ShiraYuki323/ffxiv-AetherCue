# AetherCue · FF14 技能轴浮窗

当前版本：**v1.2.6**，本次为问题修复更新。

AetherCue 是一款通过 ACT 的 OverlayPlugin 加载的技能提示浮窗。导入技能轴后，它会根据自己角色的施法日志显示后续 GCD、待插能力技，也可以只显示选定的治疗、减伤等技能。

本工具不会自动释放技能。文件在本地加载，无需启动额外服务，也不需要添加新的 ACT DLL。只有从 FFLogs 读取报告时需要联网。

## 1. 首次安装

### 准备工作

- 已安装 ACT、FF14 日志解析插件及 OverlayPlugin。
- ACT 能正常接收当前角色的战斗日志。
- 已将压缩包**完整解压**到准备长期保留的位置。请保留整个文件夹，不要只复制 HTML。

### 加载浮窗

1. 在 ACT 的 OverlayPlugin 设置中，新建一个自定义网页浮窗，并填写名称。
2. 将浮窗地址设置为解压目录中的 `overlay/index.html`，并在末尾添加 `?mode=act`。
3. 例如，解压后的目录是 `D:\ffxiv-AetherCue`，地址应填写：

   ```text
   file:///D:/ffxiv-AetherCue/overlay/index.html?mode=act
   ```

4. 初始窗口大小可设为宽 **340**、高 **280**，之后按需要调整。编辑分 P 时可临时放大窗口，完成后再缩回。
5. 返回游戏，使用自己角色的技能，检查浮窗是否开始跟随。

地址中的目录必须换成自己的实际路径。保留 `?mode=act`，可确保页面等待 ACT 日志。

直接在普通浏览器打开页面、不带 `?mode=act` 时，可以查看模拟演示；模拟演示不代表已经连接游戏。

### 移动与编辑

- **移动浮窗：**在 ACT 中关闭该浮窗的“锁定位置”和“点击穿透”，拖住主卡片的空白位置移动。
- **日常使用：**定位完成后可以锁定位置；需要鼠标穿过浮窗时再开启点击穿透。
- **打开设置、点击按钮或输入文字：**先关闭点击穿透。编辑时建议锁定位置，避免误拖动窗口。
- 如果设置面板显示不全，先在 ACT 中增大浮窗高度；完成后可再缩回日常大小。

## 2. 导入自己的技能轴

点击浮窗右下角的 **＋** 打开设置。

### 从本地文件导入

1. 在“导入技能轴”区域点击“选择文件”，或将文件拖入虚线框。
2. 支持排轴器导出的 `fight.txt`、兼容的 XIV in the Shell 战斗记录，以及本工具导出的 JSON 技能轴。
3. 检查预览中的职业、GCD 数量和能力技数量。
4. 如需修改名称或副本／首领，填写后重新点击“解析预览”。
5. 点击“保存并使用”。

也可以将文件内容直接粘贴到文本框，再点击“解析预览”和“保存并使用”。文本框支持选字、复制、粘贴及全选。

如提示有未识别技能，请先核对清单。确认接受缺失内容后，才能勾选确认并保存不完整的轴。

### 使用附带示例

本版本只附带绝伊甸黑魔示例，首次加载可直接选择；“填入示例”也使用同一条轴。`examples/` 中的 JSON 可单独导入或分享。示例用于学习操作和参考，请按自己的打法选择技能。

`examples/绝伊甸-BLM-示例技能轴.json` 为从已保存轴导出的绝伊甸黑魔示例，保留 369 个 GCD、130 个能力技／药品提示和 10 个已保存片段，不包含角色来源信息或 API 配置。

### 切换技能轴

打开设置，在“职业”和“当前技能轴”中选择需要的内容。浮窗底部的左右箭头可切换同职业的多条轴。

切换技能轴或保存显示设置会重置当前跟随进度，建议在开战前完成。

## 3. 如何看浮窗

| 显示位置或样式 | 含义 |
| --- | --- |
| 中间最大、金色边框的图标 | 下一个需要释放的技能；完整模式下为下一个 GCD |
| 左侧“当前 / 插入”区域 | 刚使用的 GCD，以及当前需要插入的能力技 |
| 后续 GCD 下方的小图标 | 提前预览这一格对应的能力技，轮到时移动并放大到待插区域 |
| 能力技上的 `+N` | 这一格还有 N 个能力技未在预览中展开，释放前面的能力技后会继续显示 |
| 红色虚线能力技 | 上一格尚未确认释放的能力技，会短暂保留提醒 |
| 底部数字 | 当前进度；发生偏离、未匹配或漏插时会附加提示 |

GCD 之间会以滑动、缩放动画过渡，已确认释放的能力技会消失。

完整技能轴中的 GCD 倒计时和进度环是根据日志估算的施法间隔，不能代替游戏里的真实冷却显示。

实际读条时，右上角主提示显示“读条 X.X s”，下方显示技能名；打断或释放成功后结束。GCD 估算归零显示“0.0 s · 等待释放”，不会自动跳过技能。瞬发技能没有读条，仍显示 GCD 估算。冲刺支持中文名、Sprint、SPRINT 和技能 ID 3，作为全职业能力技导入和确认。如果旧轴导入时跳过了冲刺，需要重新导入原文件补回。

爆发药是可选提示，不会自动确认是否已经服药。

## 4. 只显示指定技能：治疗／减伤轴

例如，只想跟随学者的几个减伤和治疗技能，可以这样设置：

1. 导入并选中对应技能轴。
2. 点击 **＋**，展开“显示哪些技能 · 治疗／减伤轴”。
3. 选择“只显示勾选技能”。
4. 按需使用“清空选择”，再勾选需要显示的技能。可通过名称或 ID 搜索。
5. 点击“保存显示设置”，然后关闭面板。

**选择区只列出这条原轴中实际出现过的技能。**同一种技能只列一项，并显示本轴使用次数；勾选后会保留它在原轴中的每次释放。列表包含 GCD 和能力技，不会列出整个职业的技能表。

如果找不到某个技能，先确认这份轴或这名角色的报告记录中是否确实释放过它。未被记录的技能不会出现在选择区。

想恢复全部内容时，选择“完整技能轴”并保存即可。

### 指定技能倒计时的规则

倒计时需要技能轴包含**逐次施法的时间点**。新版 FFLogs 导入会保留时间点；只有技能顺序的轴会显示“未附时间点”。仅重新保存旧文件不会补出时间，需要重新导入带时间点的版本，或重新从 FFLogs 读取。

1. 开战时启动第一个选定技能的倒计时。战斗中途加载、尚未开始计时时，也可以点击浮窗倒计时区域手动开始。
2. 后续倒计时使用原轴中，相邻两个**选定技能**之间的时间差。
3. **倒计时到零后会等待，不会自动跳到下一个技能。**
4. 当前提示的技能提前释放也算完成；延后释放同样算完成。
5. ACT 确认当前技能释放后，从这次实际释放的时刻开始计算下一段完整间隔。
6. 未勾选的技能不会推进进度；提前释放后面另一个选定技能，也不会跳过当前等待的技能。

例如，原轴中 A 到 B 间隔 30 秒。你实际在第 45 秒释放 A，则 B 从第 45 秒开始倒计时 30 秒。B 到零后没有释放，浮窗就继续等 B；等 B 释放后，才开始后续技能的计时。

默认开启“游戏脱战后自动重置”：完整轴、通用 GCD 和指定技能模式，在游戏真正由战斗转为脱战时都会重置进度、片段、停手状态及本把释放标记。战斗内的停手或 Boss 不可选中不会重置；ACT 单独结束统计也不会触发重置。角色死亡、换图或手动“重置进度”仍会重置。

如果某个副本的正常转场确实会让角色脱战，可以在设置底部关闭此项；开关会保存，也会随本地设置导出。需要开始新一把时可手动重置。

## 新增：通用 GCD＋勾选技能

在“显示哪些技能”中选择 **通用 GCD＋勾选技能**，勾选要特别关注的技能并保存。

- 保留完整技能轴的排列，未勾选的 GCD 换成通用图标，勾选的 GCD 保留实际图标；能力技照常显示。
- 提前释放勾选的能力技时，原位置仍显示该技能和“已提前释放”，不会因为这次释放跳动 GCD 队列。
- 提前使用后面勾选的 GCD 时，只推进一个当前通用 GCD 格，同时在那个选定技能的原位置留下提前标记。
- 到达已提前释放技能的原位置时，保留标记；随原位置正常经过后退场，不重复计算漏插。
- 同一个技能多次出现会分别记录；切 P 保留本把的提前释放标记，重置、死亡或换图时清除。

原有的 **只显示勾选技能** 模式继续保留，倒计时到零等待实际释放的规则不变。保存显示设置会重置进度，请在开战前完成。

## 新增：分 P 编辑与实战切换

### P 编号与片段名称分开编辑

“P 编号（可重复）”和“片段名称”均可修改。例如两段分别填写 `P1`／`开场`、`P1`／`停手后`，也可使用 `P1.1`、`P1.2` 等编号。多个停手片段可以属于同一个 P，不会因编号相同而合并。实战切换按片段顺序执行，编辑列表、浮窗、实战选择及导出 JSON 都保留自定义编号。

自动建议的是输出片段，不等于副本实际 P 数。请按打法修改编号、片段名称，并保存。

### 在浮窗内输入中文

如果宿主无法弹出系统输入法候选框，可以使用设置面板顶部的 **中文：内置拼音（开）**。这是本地的基础拼音选字功能，不需要服务或联网，也不修改系统输入法。

1. 将系统输入法切到英文，在阶段名称、轴名称、副本名称或技能搜索框输入拼音。
2. 浮窗会在该输入框下显示候选。按空格选择第一项，数字 `1`～`5` 选对应项，或用鼠标点击。
3. `←`／`→` 翻页，退格修改拼音，`Esc` 取消，回车按原样插入字母。
4. 可输入整条常用名称，例如 `kaichang` → 开场、`zhuanchang` → 转场、`lingjihun` → 灵极魂。没有整词候选时可逐字选择；它不具备系统输入法完整的整句联想。
5. 需要直接输入英文时，点击顶部开关切到“英文／系统输入法”。开关状态会保存。

P 编号、API、网址和 JSON 文本框保持直接输入，不会自动转换拼音；所有文本框仍可粘贴中文。

### 给 Logs 或排轴器文件分 P

1. 导入并选择技能轴，点击浮窗的 **分 P**，或在设置中展开“阶段管理”。
2. 有逐技能时间点的轴会根据长施法间隔生成分段建议；排轴器文件中的明确等待也可作为建议依据。默认识别间隔为 12 秒，可在页面调整。
3. 自动建议只是候选阶段，走位、死亡和停止输出也可能造成长间隔，需要人工核对。
4. 左侧选择要编辑的 P，右侧显示这个 P 的全部 GCD 及每格附带的能力技，包括原始时间。每页 48 组，可以翻页查看全部内容；第一 P 的起手前能力技单独列出。
5. 可修改阶段名称、前后移动起点，或选中某个 GCD 点击“设为本 P 起点”“在此处新增 P”。也可以合并相邻阶段。GCD 及其附带能力技一起归入对应阶段，不丢弃技能。
6. 点击“保存分 P 设置”。保存会重置当前跟随进度；修改内置示例时会另存为自定义轴。

只有顺序、没有时间点的排轴器轴，同样支持人工新增、调整、合并阶段以及实战切 P，但不会编造转场倒计时。分段和确认状态会保存在技能轴 JSON 与本地设置中。

### 实战时切 P

- 浮窗上方显示当前 P；左右按钮切换上一 P、下一 P，点击阶段名称或“分 P”可打开管理页面，直接选择指定 P。
- 在编辑页选中阶段只用于查看与修改，**不会切换实战进度**；点击“切到本 P”或实战阶段按钮才会切换。未保存修改时，先保存再切换。
- 切换后定位到该段起点，等待实际起手；不会凭空消耗第一个 GCD。技能确认后，以实际起手时刻重新对齐该 P。
- 恢复时优先匹配当前目标 P 开头的具体技能；相同技能有多个位置时，结合后续技能序列和原 Logs 时间辅助判断。有歧义时显示“正在对齐”，不跨 P 随意跳转，可手动选择阶段校正。
- 指定技能模式也支持切 P；该 P 没有勾选技能时会明确提示，不借用后面阶段的技能。

### 停手、转场与黑魔

- 各职业均可点击 **手动停手** 暂停普通 GCD 队列；浮窗显示停手时长。选定技能仍可记录，通用 GCD 模式中提前释放会在原位标记。
- 手动停手不会因零星施法自动解除。点击 **恢复跟随** 后，等待实际输出重新对齐；也可直接选择下一 P。
- 完整轴及通用 GCD 模式在已分段的阶段末尾进入转场等待，显示来自原记录的参考剩余时间。到零仍等待实际起手，不强行跳 P。指定技能模式在分 P 时结合原始完整轴跟踪转场。
- 黑魔的 **灵极魂** 作为弹性准备技能计数。原记录用了 3 次，你实际用 0、1 或更多次，都不会按固定次数卡住后续输出；恢复后按下一 P 起手对齐。原始灵极魂记录仍能在编辑页查看。
- 这版以角色施法记录和人工划分为依据，没有接入首领专用阶段脚本；自动建议及对齐不能保证识别所有临时变招。遇到无法匹配的起手，使用手动切 P 校正。

## 5. 从 FFLogs 报告导入

此功能由浮窗直接连接 FFLogs，无需启动本地服务。使用时需要自己的 FFLogs **V2** 客户端配置或访问令牌；分享包不附带个人 API 配置。

### 首次配置

1. 点击 **＋**，展开“从 FFLogs 报告导入”。
2. 打开“本地 API 设置”。
3. 填入自己的 **Client ID** 和 **Client Secret**；如果已有 V2 Access Token，也可改填访问令牌。
4. 需要下次继续使用时，勾选“保存在当前浮窗”。
5. 点击“连接 V2 API”。

这里使用 V2 配置，不能填入 V1 API Key。

### 读取报告

1. 粘贴可访问的公开 FFLogs 报告链接。
2. 点击“读取战斗和角色”。
3. 选择要使用的战斗，再选择一名玩家。
4. 检查显示的副本、首领及职业。
5. 点击“导入所选角色技能轴”，等待读取全部施法记录。

链接带有战斗或玩家选择信息时，会尽量自动选中对应项目；没有指定玩家时，需要手动选择。导入的是所选角色的施法记录，不会将全队技能混成一条轴。

选人列表保留角色名称便于区分；新导入到本地的轴默认命名为“首领名 · 职业”，例如“致命美人 · SCH”，不把玩家昵称或角色 ID 加到轴名中。已有轴名不会自动更改。

如果有未识别技能，会转到预览供核对；没有未识别内容时会保存并切换到导入的轴。

出现访问失败时，请根据界面提示检查网络、V2 配置、令牌是否过期，以及报告是否公开可访问。

## 6. 备份、迁移与更新

| 功能 | 导出内容 | 用途 |
| --- | --- | --- |
| 导出技能轴 | 当前原轴及其显示选择 | 分享单条轴、备份轴内容 |
| 导出本地设置 | API 配置、所有自定义轴、选轴记录、技能勾选及显示偏好 | 迁移和备份自己的完整设置 |

### 导出单条轴

打开设置，选中对应轴，点击 **导出分享 JSON**。支持文件保存窗口时可选择本地路径，否则发起普通 JSON 下载。文件名使用轴名称，不再使用内部 ID。

分享文件保留完整技能、时间点、分 P 编号和名称、显示选择，移除自动附带的角色昵称、角色 ID 与报告定位信息；不会导出 API 配置。另一位用户通过“导入技能轴”选择该 JSON，点击“保存并使用”即可。

若宿主不支持下载或没有弹出保存窗口，展开“分享文件”，点击“复制分享 JSON”，或在下方文本框按 Ctrl+A、Ctrl+C。将内容粘贴到本地文本编辑器，以 UTF-8 保存为显示的 `.json` 文件名即可。

可在“轴名称”中修改标题并点击“保存名称”。自定义轴改名会保留当前进度与分段；修改内置示例时另存为自定义轴。旧版 FFLogs 自动轴名中的角色昵称会在重新加载后清理，绝伊甸的默认名称使用“绝伊甸 · 职业”；手动命名的轴不会被自动覆盖。

### 保存完整个人设置

点击“导出本地设置”，得到 `local-settings.js`。将文件放到插件的 `overlay/` 文件夹中，再刷新浮窗，即可让该文件作为本地配置来源。

此文件包含个人 API 配置，分享技能轴时请使用“导出技能轴”，不要分享完整设置文件。

同一路径的浮窗已有浏览器存储时，会优先使用最近保存的内容。本地配置文件作为默认来源，并不会强制覆盖已有存储；迁移到新目录或新环境时，可以使用该文件恢复设置。

普通浏览器与 ACT、不同文件路径之间的存储不一定共享。换目录前请先备份。

### 更新插件

1. 更新前，导出需要保留的技能轴和个人设置。
2. 将新版文件解压覆盖到原目录，保留自己的 `overlay/local-settings.js`。
3. 在 ACT 的 OverlayPlugin 中刷新或重新加载该浮窗。
4. 如果更新说明要求重新导入技能轴，再导入相应新版 JSON。

分享压缩包不包含个人 `local-settings.js`，只提供空白模板 `local-settings.template.js`。

## 7. 常见问题

**浮窗一直等待，使用技能也不动。**

检查 ACT 是否正在接收日志、浮窗地址是否指向正确文件且带有 `?mode=act`，以及所选职业与轴是否正确。浮窗跟随自己角色的施法，队友技能不会推进进度。

**拖不动，或按钮点击没有反应。**

移动需要关闭“锁定位置”和“点击穿透”；点击按钮只需要关闭点击穿透。拖动时使用主卡片空白区域。如果这些设置已正确，仍然不能移动，请确认已经替换新版文件并在 ACT 中刷新浮窗。

**不能输入、粘贴或选择文本。**

关闭点击穿透，通过 **＋** 打开设置面板后再点击文本框。仍无效时，关闭面板后重新打开；同时确认加载的是更新后的文件。

**找不到某个职业或技能轴。**

在设置中选择职业。该职业没有可用轴时，需要先导入对应文件。

**没有减伤倒计时，或显示“未附时间点”。**

确认已保存为“只显示勾选技能”，且导入的轴包含逐次施法时间。普通排轴器文件可能只有顺序；请使用带时间点的 JSON 或重新从 FFLogs 导入。

**倒计时停在零，是否卡住了？**

这是指定技能模式的正常行为。只有 ACT 确认当前提示技能已经释放，才开始下一段倒计时。若需要从头开始，使用“重置进度”。

**之前保存的轴或 API 配置不见了。**

先确认是否换了文件夹、浮窗地址或运行环境。不同位置的存储不一定共享，可以用导出的技能轴 JSON 或个人设置文件恢复。

## 8. 按钮与快捷键

| 操作 | 作用 |
| --- | --- |
| `＋` | 打开设置与导入面板 |
| 底部左右箭头 | 切换同职业的技能轴 |
| 设置中的“重置进度” | 从头开始跟随当前轴 |
| 点击倒计时区域 | 启动指定技能模式尚未开始的首段计时 |
| `I` | 打开或关闭设置面板 |
| `R` | 重置进度 |
| `T` | 启动指定技能模式尚未开始的首段计时 |
| `[` / `]` | 切换同职业的上一条／下一条轴 |

快捷键仅在浮窗页面获得键盘焦点时生效，不是游戏内全局快捷键。实际操作优先使用界面按钮；在输入框中编辑文字时不会触发这些快捷键。
